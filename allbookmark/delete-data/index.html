모두의 북마크 데이터 삭제 방법

앱: 모두의 북마크 (개발자: Neo Visioning) · 2026년 10월 27일

모두의 북마크는 회원가입이 없고, 북마크는 사용자의 휴대폰에 저장됩니다. 운영자의 서버에는 북마크가 저장되지 않으므로 운영자에게 삭제를 요청할 데이터가 없습니다. 아래 방법으로 사용자가 직접 지울 수 있습니다.

1. 휴대폰 안의 북마크

  • 북마크 하나: 카드의 ⋮ 메뉴 → 삭제
  • 여러 개: 카드를 길게 눌러 선택 → 전체 선택 → 삭제
  • 모두: 휴대폰 설정 → 앱 → 모두의 북마크 → 저장공간 → 데이터 삭제, 또는 앱 삭제

앱 데이터를 지우면 북마크, 분류, 태그, 메모, 알림 예약이 모두 지워집니다. 자동 백업 파일(다운로드/모두의북마크 폴더)과 직접 저장하거나 보낸 백업 파일은 남으니 필요하면 파일 앱에서 지워 주세요.

2. 여러 기기 동기화(Pro) 데이터

동기화를 켠 경우 북마크가 사용자 본인의 Google 드라이브 앱 전용 폴더에도 저장됩니다.

  • 앱에서: 설정 → 동기화 끄기 → "끄고 드라이브의 이 기기 파일도 지우기"
  • 모든 기기 파일 한 번에: Google 드라이브 설정 → 앱 관리 → 모두의 북마크 → 옵션 → 숨겨진 앱 데이터 삭제
  • 접근 권한 끊기: Google 계정의 연결된 앱에서 모두의 북마크 연결 해제

지운 동기화 데이터는 바로 삭제되며 운영자가 따로 보관하지 않습니다.

3. 광고와 결제

무료 버전의 광고(Google AdMob)가 처리하는 광고 ID는 휴대폰 설정 → Google → 광고에서 재설정하거나 삭제할 수 있습니다. 결제 기록은 Google Play가 관리하며 Google Play 고객센터를 통해 요청할 수 있습니다.

자세한 내용은 개인정보 처리방침을 참고해 주세요.
